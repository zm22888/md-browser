# MD Browser 演示文档

这是 **Markdown 浏览器** 的演示目录，用来验证阶段 1 的核心能力。

## 使用方式

- 左侧是文件树，点击文件即可打开
- 右侧是大纲面板，点击标题跳转
- 目录变动会实时刷新（试试新增/删除一个 .md 文件）
- 右上角可以切换亮色 / 暗色主题
